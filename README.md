# PRO192 - HỆ THỐNG ÔN THI & THI THỬ LẬP TRÌNH HƯỚNG ĐỐI TƯỢNG VỚI JAVA (OOP JAVA FE)

Hệ thống ôn luyện và thi thử trắc nghiệm Final Exam môn **PRO192 (Object-Oriented Programming with Java)** dành cho sinh viên Đại học FPT.

🌐 **Website trực tuyến:** [https://vuminhtuan-cdm.github.io/pro192-fe/](https://vuminhtuan-cdm.github.io/pro192-fe/)

---

## 🌟 Tính Năng Nổi Bật

1. **3 Chế độ học tập & thi thử toàn diện:**
   - 📖 **Chế độ Ôn Tập:** Xem đáp án chuẩn, giải thích chi tiết, highlight cú pháp Java OOP.
   - ⚡ **Thi Thử Luyện Tập:** Chọn đáp án và nhận phản hồi Đúng/Sai ngay lập tức kèm đáp án chuẩn.
   - ⏱️ **Chế độ Thi Thử Chuẩn FE:** Đếm ngược thời gian chuẩn (60 phút / 50 câu), nộp bài tính điểm thang 10, hiển thị bảng tổng kết và chế độ Review chi tiết từng câu.
2. **Hỗ trợ đầy đủ câu hỏi đơn & câu hỏi chọn nhiều đáp án (Multi-choice):**
   - Tự động nhận diện câu hỏi chọn nhiều đáp án (`Choose multiple correct answers`), hiển thị dạng checkbox với nút `Kiểm tra đáp án`.
3. **Đảo câu hỏi ngẫu nhiên (`🔀 Tráo câu hỏi`):**
   - Xáo trộn thứ tự câu hỏi ngẫu nhiên trong cả 3 chế độ giúp rèn luyện phản xạ, chống học vẹt.
4. **Hỗ trợ phóng to hình ảnh (Lightbox):**
   - Bấm vào bất kỳ hình ảnh đề thi nào để xem kích thước lớn, sắc nét.
5. **Hiển thị công thức KaTeX & Code Block:**
   - Định dạng chuẩn đẹp các đoạn mã Java và công thức kỹ thuật.
